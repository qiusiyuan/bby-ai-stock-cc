# 久期光谱 + 双轴框架 — 判断哪些持仓最怕加息

> 一份可复用的分析透镜。**每次看到利率/CPI/FOMC 新闻时,对着这条谱系,就能快速判断自己哪些持仓最该担心、哪些几乎不受影响。** 不是股票分析,是「怎么想」的框架。
>
> 起源: 2026-08-25 report MU deep-dive 的追问 —— 「什么是长端收益率上行、分母是什么」+「AMZN/MSFT 算价值还是成长」。

```callout info
**核心一句话**: 别问「是价值股还是成长股」——那是假二分法。问两件事: (1) 这家公司的价值有多少在「近处已经在赚」、多少在「远处才兑现」?(2) 远处那部分有多确定?**近处占比越高 + 远处越确定 → 越抗利率;越靠远期 + 越不确定 → 越怕加息。**
```

## 1. 为什么利率能决定股价 —— 「分母」的机制

股票价值 = **把公司未来每一年能赚的钱,折算回今天的一笔钱**。为什么要折?因为明年的 1 块钱不如今天的 1 块钱值钱(今天的钱能拿去买国债赚无风险利息)。

折算公式(理解即可,不用背):

    今天的价值 = 未来某年的现金 ÷ (1 + 折现率)^年数

- **折现率 = 分母** = 「钱的时间成本」= 无风险利率(国债收益率)+ 风险溢价。
- 折现率越大 → 分母越大 → 未来的钱折回今天越不值钱 → 股价该越低。

**股票是长久期资产(现金流拖很多年),所以对标的是长端国债(10Y/30Y),不是短端。** 长端收益率往上顶(如 2026-08 的 10Y 4.64% / 30Y 逼近 5%),就是在抬高所有股票分母的地基。

## 2. 为什么成长股受伤比价值股大 —— 指数级放大

分母里有个 `^年数`(指数)。同样加 1 个百分点,越远的现金流被砸得越狠:

```compare
这笔现金在… | 折现率 4% 时值 | 折现率 5% 时值 | 变化
1 年后的 $100 | $96.2 | $95.2 | −1.0%
5 年后的 $100 | $82.2 | $78.4 | −4.7%
10 年后的 $100 | $67.6 | $61.4 | −9.1%
```

**同样 +1pp 利率,10 年后的现金流被砸的力度是 1 年后的 ~9 倍。** 这就是「久期」:一只股票价值越靠远期现金流,它就越像一张长期债券,利率一动它就大幅波动。**成长股 = 长久期资产。**

## 3. 久期光谱 —— 把持仓排上去

```compare
位置 | 代表持仓 | 现金流特征 | 对利率敏感度
价值端 (近+稳) | CVX, CNQ, SU, HXE.TO, IBM | 现在就在赚、马上分红 | 低
优质成长 (有地板+博未来) | MSFT, GOOG, AMZN, META, AAPL | 当期巨额 FCF + 远期增长期权 | 中
高动量成长 (周期/抢跑) | MU, TSLA, AMD, MRVL, NVDA* | 盈利周期性或大部分在远期 | 高
极长久期 (几乎全在远期) | SPCX, HUMN, KOID, CROB | 无当期盈利, 纯赌未来 | 极高
```

（*NVDA 当期 FCF 巨大,但估值里赌的未来增长也巨大,所以偏高动量档,比 MSFT 久期长。）

## 4. 双轴框架 —— 远近 × 确定性

两只都「有现金流又博未来」的股票,为什么利率敏感度天差地别?因为要看**两条轴**,不是一条:

- **轴一 · 久期(远近)**: 价值有多少在近处已经在赚 vs 远处才兑现。
- **轴二 · 确定性**: 远处那部分现金有多靠谱 → 决定「风险溢价」这半个分母。

### 对照案例: MSFT(中间/抗利率) vs MU(高动量/怕利率)

**MSFT / AMZN / GOOG —— 为什么是「有地板的成长」,抗利率:**
1. **有真实的当期现金地板**: Azure / AWS / 广告是现在就在收、而且是订阅制/经常性的钱 → 一大块价值坐在「近处」栏 → 分母抬高时这块几乎不受伤。
2. **远期更确定 → 风险溢价低**: 宽护城河、垄断份额、定价权 → 市场信它 5 年后还在高利润运转 → 即使利率涨也不用额外多打折。
3. **避险时是「科技里的避风港」**: 不确定性升高时资金躲进「又赚钱又成长」的巨头 → defensive-growth 属性(2026-08 近 30d: MSFT +27.5%、AMZN +5%,而 MU -6%、TSLA -11%、humanoid 全线负 —— 但 MSFT 那部分也有强财报功劳,别全归久期)。

**MU —— 为什么「有现金流」却排高动量档,怕利率:**
1. **地板不被信任**: 现在赚的是**周期顶部暴利**(peak earnings),市场认为随时均值回归 → 这块近处现金不能当稳定地板,被打折。表面 6-7x P/E 是「假便宜」(peak earnings ÷ 高价 = 低倍数,周期顶部特征)。
2. **远期不确定**: 内存是**商品生意**(涨价驱动、无长期定价权)→ 远期现金确定性远低于订阅制 → 风险溢价高。
3. **结果**: 既没有 MSFT 那种可信当期地板,又没有确定远期 → 几乎纯按「AI 超级周期还能演几年」的远期故事 + 高 beta 定价 → 久期长,跟利率一起呼吸。**证据**: 8/18 MU -7.1%,催化剂之一就是「10Y 顶 52w 高」,公司毫无利空。

## 5. 债务化交易的「双刃」—— 为什么对 MU 净偏负

弱美元 / 债务化环境里,两股方向相反的力同时作用:

```compare
力 | 作用侧 | 方向 | 说明
弱美元→资金逃向风险/实物资产 | 分子/情绪 | ➕ 温和正面 | 高 beta 动量股(含 MU)得到部分 bid
债务化的实现机制=长端收益率上行 | 分母/折现率 | ➖ 负面 | 折现率地基抬高, 压长久期估值
```

**净偏负**: 因为 MU 经验上沿利率通道交易(10Y 一冲高它就跌),分母那侧的力更直接、更持续 → 抵消后净偏负。

## 6. 怎么用这个框架(实操)

**每次看到利率/通胀/FOMC 新闻,按这个顺序过一遍持仓:**

1. **利率往上(鹰派 / CPI 烫 / 长端破位)** → 先看**极长久期档**(SPCX、humanoid)最受伤,再看**高动量档**(MU、TSLA、MRVL);**价值端**(CVX、CNQ)几乎不动甚至逆势(实物资产+派息)。
2. **利率往下(鸽派 / CPI 降温 / 久期解压)** → 反过来: 极长久期档弹性最大,是最干净的上行标的;价值端跑输。
3. **判断某只「成长股」到底多怕利率** → 套双轴: 当期地板可信吗?远期确定吗?两个都「否」= 最怕(MU 型);两个都「是」= 最抗(MSFT 型)。

```verdict watch
利率是长久期持仓的公因子。看利率新闻时先定「往上还是往下」,再对着光谱从极长久期端开始点名 —— 这比逐个股翻财报快得多。
```
