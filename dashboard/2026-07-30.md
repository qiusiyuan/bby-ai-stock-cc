### 🎯 重大事件：FOMC 7月决议

**是什么：** Federal Open Market Committee（联邦公开市场委员会）每年8次议息会议，决定联邦基金利率目标区间。7月30日是2026年第四次会议。

**结果：** 维持利率不变（5.25-5.50%区间），符合市场100%预期。

**为什么今天重要：**
- 上次6月会议暗示"年内1次降息"，今天的发言稿措辞是否更鸽？是今日焦点

**传导路径：** 维持不变 → 实际上比预期微鸽（暗示9月降息窗口打开） → 美元轻微下行 → 成长股/高倍率股受益 → memory stock叙事中"降息周期启动 → DRAM超级周期加速"概率微升

**对持仓影响：**
- TSLA / NVDA / SPCX：高倍率股，降息方向长期利好
- MU / SKHY：DRAM周期 + 降息组合 = 双重顺风

## Deep Dive: SNDK +24.2%（闪迪为什么大涨）

**SNDK今天是S&P500涨幅第一名，+24.2%**

### 背景：SNDK是什么

闪迪（SanDisk）2023年从Western Digital分拆独立上市，专注**NAND闪存**（区别于DRAM）。主要产品：企业级SSD、消费级存储。在memory stock里，SNDK代表NAND侧，MU/SKHY/Samsung代表DRAM/HBM侧。

### SNDK今天涨的具体原因

**1. 直接触发：MSFT Azure beat +36% → NAND需求重估**

数据中心扩张 = 更多服务器 = 更多SSD需求（每台AI服务器需要数TB的NVMe SSD用于模型权重/checkpointing/caching）。MSFT的Azure数据证明hyperscaler采购周期不减速。

**2. 技术性超卖反弹**

SNDK 5天跌了 -21.6%，30天跌了 -36.6%，离52周高点$2354已经跌了近50%。forward P/E只有5.9x——vs 历史平均15-20x。在"AI capex恐惧"叙事驱动的杀跌里，SNDK被过度卖出。

MSFT的数字提供了"恐惧叙事是错的"的反证，超卖股票弹得最猛。

**3. 中国NAND竞争叙事暂时搁置**

近期压制SNDK的主要叙事之一是"中国NAND（YMTC）产能扩张 → NAND价格战 → SNDK利润压缩"。今天MSFT数据暂时让市场关注需求侧（hyperscaler需求强劲）而非供给侧（中国竞争），导致这个负面叙事被搁置。

注意：明天的新闻已经有"Sandisk (SNDK) Stock Slides As Chinese Memory Competition Rattles NAND Outlook"标题出现——这个叙事可能明天重回主导，需要密切观察。

### 这次涨能持续吗？

**支持持续的：**
- Forward P/E 5.9x极低，AMZN财报若继续确认AI需求，NAND估值修复有空间
- hyperscaler采购通常提前6-12个月锁定，MSFT/AMZN的capex支出意味着NAND实际采购已经发生

**反对持续的：**
- 中国NAND竞争是结构性问题，今天的新闻只是暂时搁置
- SNDK还在$1262，离MA50 $1712还有35%的距离，技术面仍然偏弱
- 本质上，今天的涨是"恐惧叙事证伪 + 超卖反弹"的组合，不是"SNDK基本面改变"
