# Journal 2026-11-04

## 1. 一个系统性盲区被一次事件同时暴露在 9 个标准上

四个月来「AI 建设可持续性」的全部跟踪都在**融资轴**上:10/14-10/22 信用抛售、10/20 Meta-Nvidia 债务保险创纪录、10/22 四家 CDS 新高、10/27 Meta 股权募资绕开债市、10/29 capex÷经营现金流比率排序惩罚。工作簿为此建立了「内生融资 vs 需要外部资本」判别轴,并连续五天验证它。

今天出现第二条轴:**客户有钱也可能不被允许建**。而检查结果是 —— **GEV / MU / DRAM / NVDA / MRVL / AVGO / TSM / INTC / AMD 九个标的的全部 kill conditions 里,零条覆盖「监管/许可/地方政府对数据中心建设的限制」**。

这不是某一条触发器写错了,是**整个 kill-condition 体系只覆盖了「需求」和「技术」两类风险,没有「准入」这一类**。而今天 -9.3% / -7.0% / -7.1% 的全部内容是准入。

**可操作纠正:** 写 kill condition 时,除了问「需求会不会消失」「技术会不会失败」,必须问第三个问题:「**这门生意需要谁的批准?那个人会不会换?**」对 GEV 是州议会与公用事业委员会;对 SPCX 是 FCC 与外国政府;对 TSLA 是 NHTSA 与州 DMV。这三个都在今天被同一个事件改变了,而三个 thesis 全都没写。

## 2. kill-condition 错配出现第五种形态:「触发者错」

前四种形态的分类(来自 10/15-11/02 的累积):

| 形态 | 含义 | 案例 |
|---|---|---|
| 机制错 | 条件度量的机制不是正在定价的机制 | NOK / META 信用轴 |
| 维度缺 | 整个风险维度不在五条里 | SPCX 竞争维度 |
| 度量错 | 方向抓对了但选错了度量指标 | META 用营业利润率而非 FCF |
| 时间分辨率不足 | 缓冲期长于定价变化速度 | TSLA #4 的两季缓冲 |

今天新增第五种:**触发者错 (wrong agent)**。

- GEV kill #1:「**Hyperscalers** 公开削减数据中心建设 >20%」
- DRAM kill:「主要 **hyperscaler** 发出 AI 基础设施 capex 削减信号」

两条都可能在今天的事件链末端被字面触发(若州级暂停令确实导致 hyperscaler 削减),但**条件的设计意图是捕捉需求自发走弱,而实际发生的是供给侧被行政限制**。这两种情形对持仓的含义完全不同:前者是需求消失(永久),后者是需求延后(可能只是时间)。条件无法区分它们,所以即使触发了也不告诉你该做什么。

**纠正方式:** kill condition 的措辞里,**行为主体和行为内容要分开写**。不是「hyperscaler 削减建设」,而是「数据中心新建容量(无论何种原因)连续两季同比下降 >20%」+ 单独一条「任一占全美规划产能 >15% 的州实施暂停令或等效限制」。前者度量结果,后者度量原因。

## 3. thesis 的 Bear 情景文本与 kill condition 不一致 — 一个可推广的设计缺陷

GEV thesis 的 Bear 情景(25%,目标 $700-750)**原文写的就是**:「hyperscalers defer data center buildout」。

今天发生的正是这件事的州级版本。**Bear 情景在实质上前进了一步,而四条 kill condition 全部零触发。**

原因是:Bear 情景是用**散文**写的(「推迟建设」—— 不管谁推迟),kill condition 是用**可测量条件**写的(「hyperscaler 公开削减 >20%」—— 指定了主体和幅度)。把散文收紧成条件的过程中,把「不管谁推迟」收紧成了「hyperscaler 自己决定推迟」,丢掉了最可能发生的那种情形。

**可操作纠正:** 每次写 kill condition 时,逐句对照 Bear 情景文本,确认每一句 Bear 描述都有一条对应的可测量条件;如果某句 Bear 描述无法被测量,那应该记为「已知不可测量的 Bear 分支」而不是悄悄省略。**今天这一条如果早做,GEV 的触发器会在今天响,而不是在价格已跌 9.3% 之后由人工发现。**

## 4. 「加息打击高倍数股」的替代规则今天第一次有机会检验,结果是不适用

11/02 删除了「加息打击高倍数股」这条规则(七次检验七次否证),并提出替代规则:**横截面分化由「当天有无具名公司事实」解释,倍数只在无公司新闻时成为残差变量**。

今天的横截面检验:远期 PE 从 MU 3.83x 到 TSLA 178.39x 跨 **46.6 倍**,而涨跌排序是 —— **最贵的 TSLA(178x)跌 3.34%,最便宜的 MU(3.83x)跌 7.00%**;MSFT(22.99x)涨 6.68%,SKHY(3.38x)跌 5.12%。倍数与涨跌幅零相关。

但**替代规则今天不适用**,因为前提不成立:今天有一条压倒性的政策事实,所有标的的涨跌都由「对该事实的敞口」解释(开支方 vs 供给方 / 数据中心敞口占比 / 油价敞口)。所以今天既不否证也不验证替代规则。

**真正该检验替代规则的窗口仍未出现。** 下一个候选是 11/06 NFP 之后到 11/17 NVDA 之间,如果那段时间出现一个既无公司新闻又无政策新闻的交易日。**注意不要把今天记成一次检验** —— 11/02 的教训正是「在只有一个候选机制时把残差归因给那个机制」,今天的残差几乎为零,没有残差可归。

## 6. 能源捕获率:下行侧不放大,但今天的样本被污染

10/28 的发现是「上行捕获率不是常数而是油价绝对水平的函数,在区间上端钝化」(当时 WTI 口径 45-61%)。今天是下跌日,捕获率 SU 57% / CVX 47% / CNQ 93% / HXE.TO 67%(Brent 口径 55/45/89/64)。

**落在同一个区间内 → 不支持「下行侧放大」的假说。** 但必须标注污染项:**CNQ 的 93% 是四只里唯一接近 1:1 的,而它明天出财报且量比 2.92x 为全场最高** —— 卖压里有仓位清理成分,所以这个 93% 不是干净的 beta 读数。

去掉 CNQ 后区间是 47-67%,和 10/28 的 45-61% 几乎重合。**暂定结论:能源三只(SU/CVX/HXE)对油价的捕获率在 45-67% 之间且不显著依赖方向。** 下一次检验要选一个没有个股事件的油价大动日。
