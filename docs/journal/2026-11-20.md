## 2. kill-condition 错配 —— 样本已足够大，应当改设计而不是继续记案例

今天 10 只名字处于破位或准破位，**零只因自己预设的 kill condition 触发**：

| 名字 | 实际定价的风险 | 预设条件写的是 |
|---|---|---|
| NVDA | 监管/司法调查 + 关键人离任 | 营收减速 / DC 失速 / 毛利率跌破 65% |
| MU / SKHY | 第三方 2027 定价预期转负 | 毛利率压缩 / 指引下修 / Samsung 认证 |
| AVGO | 客户换供应商 | AI 营收不达翻倍承诺 |
| GEV | 长周期订单折现率上行 | Power 利润率崩塌 + Wind 亏损 |
| SNDK | NAND 2027 定价 | 毛利率连续两季压缩（实际 85% 仍上行） |
| INTC / NOK / MRVL / GOOG | 折现率 + 风格 | 各自的基本面恶化路径 |

**这不是第十个案例了，是一个系统性设计缺陷。** 所有 kill condition 都写在同一个维度上：**本期基本面恶化**。而过去两周的定价变量是三类完全不同的东西：

1. **分母类**（折现率）—— GEV、HUMN、SPCX、INTC。无法用公司数据触发，只能用相对表现触发。
2. **规则类**（监管/司法/出口管制）—— NVDA、TSM。事件型，无连续指标。
3. **关系类**（客户/供应商结构变化）—— AVGO、MRVL。可以用「单一客户占比」或「客户公开换供应商」触发。

**提议的修正（下次 refresh-thesis 时落地）**：每只股票的 `triggers.yaml` 增加三类条目，而不是继续往 `kill_conditions` 里堆基本面条件：

```yaml
kill_conditions:        # 现有：本期基本面恶化
re_read_triggers:       # 现有
structural_triggers:    # 新增：关系类（客户换供应商 / 单一客户占比变化 / 供应链关系人离任）
regulatory_triggers:    # 新增：规则类（针对本公司的调查启动 / 出口管制条文生效 / 诉讼进入实体审理）
# 分母类不单列 —— 它是组合层问题，不是个股层问题，应放在 pulse 的久期分层里处理
```

GEV 是检验这个设计的最好案例：若它明日破位，按现行流程会触发一条为「Power 利润率崩塌」写的线，而 Power 利润率今天在扩张。处理方式应当是「修正预设条件」，而不是「thesis 被否证」—— 这一点已写进 Focus: 电力/Grid 的 verdict，但那是单次处理，不是制度。

## 4. 11/19 的一条判断在一天内需要修正

11/19 写的是：「资金分流的对手方第一次来自板块外部 —— 一个新上市的需求端标的」。

今天 ANT 自己跌 10.90%、盘中触及发行价，^SOX −8.12%。**钱不是流向 ANT，是流出整个 AI 复合体。** 11/19 观察到的不是板块内重新分配，而是整体撤出的第一天。

**错在哪**：用单日的资金流向差异（ANT 上市吸金 vs 供应商下跌）推断了一个结构性结论（「对手方来自板块外部」），而单日 IPO 抽水在时间序列上无法与「整体撤出的第一天」区分。当时应标为低置信度，或直接写成「今日的现象」而不是「第一次出现的结构」。

**修正的方法论**：IPO 首日/次日的资金流不能作为板块结构判断的依据 —— 新发行的抽水效应与板块撤出效应在 T+1 之内同形。需要至少 3 个交易日，或者需要看 ^SOX 这类正交指标（今天证明它能区分）。

## 8. 一个尚未解决的方法论问题

今天七条公司级利好里只有一条所在的标的收正（GOOG，而它的「利好」其实是削减他人订单）。11/16 是八条全部无效，11/19 是七条无一完整保留，11/20 是七条里一条。

**三天的样本都指向同一件事：当前 regime 下公司级消息对价格的解释力接近零。** 但目前没有一个量化的方式来判断这个 regime 什么时候结束。

INTC 可以当基准线 —— 它同时满足「低估值」+「连续好消息」，两者同时失效。只要 INTC 这类消息继续无效，regime 未变；一旦被定价，regime 变了。这是一个单股代理，粗糙但可观察。

更好的做法可能是：每天统计「公司级利好数 / 其中对应标的收正数」的比率，连续跟踪。若该比率从当前的 1/7 回到 4/7 以上，说明基本面定价恢复。**但这需要一个新的记录字段，目前 attributions 索引里没有。** 待定。
