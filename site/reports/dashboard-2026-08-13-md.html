今日故事：SanDisk 是催化剂，不是主角

早盘 SNDK 发布"multi-year 财务模型" — 三个核心数字： 1. 营收增长 CAGR 大幅上调（具体数值待官方新闻稿；市场反应 = 显著高于市场预期） 2. 毛利率目标区间 提升 3. 股东回报框架 (buyback/dividend) 加码

这本来是 SNDK-specific 事件，但市场把它广义化为 "整个 memory 供给端都在拧紧螺丝"，理由： - SanDisk 是纯 NAND 玩家 (WD spinoff)。它上调的信号 = NAND 供给端不再降价 - 若 NAND 不再降价 → DRAM (MU/SKHY 主业) 更没有理由降价，因为 DRAM 一直是供给更紧张的品种 - 传导到 HBM (MU/SKHY 增量): HBM 定价是 DRAM 定价 + Yield premium，若 DRAM 定价硬 → HBM 更硬

所以今天 SNDK +15.3% → MU +6.28% → SKHY +8.3% → DRAM ETF +5.33% 是 "NAND 上调 → 全 memory read-through" 的连锁传导。
