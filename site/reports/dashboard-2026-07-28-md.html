MU
$824
from ATH -34% · PE_f 5.4x · MA50 $958 (below) · MA200 $509 (above)

直接催化: 1. "AI Chip Trade Narrows to NVIDIA" — Morgan Stanley Mike Wilson 公开解释: 投资者在减持 memory/chip, 因为 AI capex 的利润只归 NVDA, memory 是 "必需品但非利润中心" 2. SNDK (SanDisk) 上市即 -30% — NAND 弱势信号, 虽然 MU 是 DRAM/HBM 故事但情绪传染 3. 今天 SK Hynix 报前避险 — 不确定性 + 连续下跌 momentum → 资金在 earnings 前减仓

深层逻辑: 市场的疑问不是 "HBM 有没有需求" (有), 而是 "memory 能维持超额利润多久": - HBM 毛利率 ~80%+ (当前) → 但 SK Hynix/Samsung 产能爬坡 → 竞争压力何时显现? - NVDA 有 CUDA 壁垒, MU 的 HBM 有什么壁垒? → 答案是产能+良率+客户锁定, 但市场不确定 - PE 5x = "cyclical stock priced for cycle peak" — 市场在说 MU 当前利润是周期顶

Valuation context: - PE_f 5.4x → 上一次 5x 是 2023 年初 (当时 $55, 之后涨 15x 到 ATH $1255) - 如果 HBM 需求持续 (大概率) → 这是历史性低估 - 如果 HBM 竞争加剧 + ASP 下降 → 利润回归均值, 5x PE 变成 10x PE (股价还是现在水平)

今天 SK Hynix 的 read-through: - HBM 营收占比 (如果 >50% + guide up → MU 反弹) - HBM margin (如果维持 → "不是 commodity" argument 成立) - NVDA 供货指引 (如果 HBM4 提前量产 → MU 也受益, 因为 MU HBM4 roadmap 相同)

PE 5x 是极端值 — 要么是绝佳买点, 要么是 cycle top 的经典陷阱。SK Hynix 今天报是短期方向判断, MSFT 明天报是中期叙事判断。两个都 beat → 底部信号明确。
